# CodeAlpha Simple E-commerce Store

A full-stack e-commerce web application developed as part of the CodeAlpha Full Stack Development Internship.

The application allows users to browse products, manage a shopping cart, register and log in, place orders, and view their order history.

## Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite
- Git and GitHub

## Features

- Responsive product listing page
- Individual product details
- User registration and login
- Secure password handling through Django authentication
- Shopping cart with quantity updates
- Add and remove products from the cart
- Checkout with form validation
- Cash on Delivery orders
- Order history for logged-in users
- Product and order management through Django Admin
- Product stock validation and automatic stock updates
